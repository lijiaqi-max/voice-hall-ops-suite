# 比赛演示手册

## 一分钟复位

```powershell
cd D:\int\voice-hall-ops-suite
.\scripts\reset-demo.ps1
.\scripts\start-demo.ps1
```

打开 `http://127.0.0.1:4173`，使用：

- 账号：`demo-owner`
- 密码：`Demo-Owner-12345`

结束后运行：

```powershell
.\scripts\stop-demo.ps1
```

演示数据库固定保存在 `build/demo/voicehall.mv.db`，与开发数据库隔离。每次复位会重建两厅、成员、排班、绑定、排麦、麦时、官方流水、结算规则、支出和待处理作业。

## 八分钟主线

1. `0:00-0:45`：说明排班、麦时、账单和关系跟进分散的问题。
2. `0:45-2:30`：打开“主持排班”和“厅控数据”，展示队列、绑定、麦时及出勤。
3. `2:30-4:00`：打开“流水导入”，展示官方账单历史、SHA-256 去重和金额校验。
4. `4:00-5:15`：打开“财务结算”，展示整数分计算、明细、净利润、勾稽差额 0 和 XLSX 导出。
5. `5:15-6:45`：打开“关系库”和“作业中心”，展示价值分层、禁止联系、任务分配和人工确认的 AI 建议。
6. `6:45-7:30`：展示成员提交、管理审核、权限隔离和审计记录。
7. `7:30-8:00`：总结私有部署、官方账单权威来源、无自动私信和后续商业化路线。

## 十五秒兜底

- 微信或映客真机页面变化：立即停止真机操作，切换管理台“厅控数据”中的确定性模拟记录。
- VPS 网络异常：切换本机演示环境，数据和交互路径一致。
- AI 服务未配置：接口自动返回规则模板，并继续显示风险标签与“必须人工确认”。
- Android 投屏异常：播放预先录制的排麦、上麦和断线恢复片段，管理台继续走财务与作业主线。

## 演示前检查

- `.\scripts\smoke-web.ps1`
- `.\scripts\reset-demo.ps1 -SkipBuild`
- 确认 `artifacts/SHA256SUMS.txt` 为最新构建生成。
- 确认成员端无无障碍权限，厅控端正式适配器仍显示校准状态。
- 真机失败时不得宣称微信自动回复或映客识别已经真实验证。
