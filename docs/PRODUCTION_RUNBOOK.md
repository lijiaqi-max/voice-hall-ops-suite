# 生产上线运行手册

## 上线前置条件

- VPS 已安装 Docker Engine 和 Docker Compose v2，域名 A 记录已指向 VPS。
- `.env` 已配置强随机 `JWT_SECRET`、32 字节 Base64 `DEVICE_MASTER_KEY`、数据库密码、MinIO 密码和 `BACKUP_PASSPHRASE`。
- 两台 Android 真机已安装正式 APK：一台选择微信机器人端，一台选择映客采集端。
- AI 建议默认使用规则模板，不配置外部 AI 密钥。

## 部署验收

```bash
cd voice-hall-ops-suite/infra
docker compose --env-file .env up -d --build
curl -fsS https://DOMAIN/api/health
./backup.sh
./restore.sh ./backups/voice-hall-YYYYMMDDTHHMMSSZ.tar.gz.enc
```

健康检查必须返回 `status=ok`。恢复演练后，账号、厅房、设备和审计数据必须一致。

## 空库业务初始化

1. 首次登录后立即修改 bootstrap 密码。
2. 创建所有者、管理员、财务、排班员、成员账号，关键账号启用 TOTP。
3. 创建组织下的厅房、成员、主持、结算规则和联系限制。
4. 每天按官方 CSV/XLSX 账单导入流水，官方账单是唯一金额来源。
5. 关闭结算期前确认待分配流水、主持麦时和异常记录都已处理。

## 生产设备注册

1. 管理台“厅控数据”生成 10 分钟一次性设备注册令牌。
2. Android 厅控端输入 `https://DOMAIN/api`、设备名和注册令牌。
3. 注册成功后，管理台设备列表应显示设备角色、启用状态和待校准能力。
4. 完成真机验收后，在管理台启用对应能力，并在 Android 本机启用对应正式能力。
5. 禁用设备后，该设备新的签名事件必须被拒绝。

## 正式自动化开放标准

- 微信：仅处理配置的单个群和白名单指令；未知消息、非目标群、页面不可读、输入框或发送按钮不可验证时停止。
- 映客：仅采集当前可见语音房麦位；页面不可读、后台、中断或节点不足时停止，不推算时长。
- 不允许固定坐标兜底，不自动私信，不处理验证码、安全提示或登录流程。

## 24 小时上线观察

连续 24 小时必须满足：

- 无重复回复。
- 无重复计时。
- 无越权查询。
- 备份可恢复。
- 完成一轮真实账单导入到结算报表闭环。
